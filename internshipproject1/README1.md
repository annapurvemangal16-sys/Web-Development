
# Contact Form Project

## Description
A responsive contact form using HTML, CSS and JavaScript.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Features
- Email validation
- Message length validation
- Error messages
- Success message
- Dark mode toggle
- Save dark mode preference
- Responsive design

## Project Structure
ContactForm/
├── index.html
├── style.css
├── script.js
└── README.md

## How to Run
1. Download or create the project folder.
2. Open the folder in VS Code.
3. Open index.html in a browser.
4. Enter email and message.
5. Click Send Message.
6. Test the dark mode button.

## Validation Rules
- Email must have a valid format.
- Message must contain at least 10 characters.

## Note
This is a frontend-only project.
It validates the form but does not send emails.
