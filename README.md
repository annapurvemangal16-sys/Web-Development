# Personal Portfolio Website

## Project Overview

This project is a personal portfolio website created
using HTML5.

## Objectives

- To learn basic HTML concepts.
- To create a personal portfolio.
- To display personal information and skills.
- To create navigation links.
- To build a contact form.

## Technologies Used

- HTML5
- Visual Studio Code
- Google Chrome

## Project Structure

- index.html: Main website file
- README.md: Project documentation
- 

## How to Run

1. Download or clone the project.
2. Open the project folder.
3. Open index.html in a web browser.

## Testing

- Checked navigation links.
- Checked form input fields.
- Checked website structure.
- Checked image paths.

## Conclusion

This project helped me understand HTML tags,
elements, forms, links, and semantic HTML.
